## Usage

Each tool lives in its own subdirectory with its own `README.md` describing
installation, dependencies, and usage.

```bash
git clone https://github.com/EEI-Charles-University/molevo-toolkit-pub.git
cd molevo-toolkit-pub/<tool_name>
```
